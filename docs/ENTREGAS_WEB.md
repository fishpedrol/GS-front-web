- [ ] No mínimo 8 componentes React organizados e reutilizáveis
- [ ] `useState` e `useEffect`
- [ ] No mínimo 2 custom hooks separando a lógica e o estado da camada visual
- [ ] A lógica de negócio e o acesso aos dados separados dos componentes
